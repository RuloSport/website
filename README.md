# rulosport.com

Static website for RuloSport (Padel AB Pty Ltd), hosted on GitHub Pages.

- Pages are generated by `tools/build.py` (run from a folder containing `assets/`; output goes to `site/`, which is copied to the repo root).
- Product photos are served from DemoPadel's Shopify file storage.
- Retail "Buy now" buttons link to the Rulo products on demopadel.au.
- Wholesale and contact forms post to Formspree (endpoint set in `assets/site.js`).
